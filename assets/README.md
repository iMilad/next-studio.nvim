# Artwork and screenshots

`logo.svg` and `banner.svg` were drawn from basic geometric shapes specifically
for NEXT Studio. No stock artwork, icon pack, third-party logo, tracing or font
file is included. The three panes represent editor, agent and terminal; the amber
corner represents focus. The banner uses the viewer's system font.

The original artwork is distributed under the repository's [MIT license](../LICENSE),
with the same permission to use, modify and redistribute it as the code.
This describes the source and license of these assets; it is not a trademark
clearance or a claim of exclusive rights to generic shapes or the project name.

## Screenshot provenance

All four PNGs are rendered from the actual Neovim UI line grid in an isolated
session running this plugin. They show a synthetic `orchard` project, sample
source, sample Notes and a local demo shell. They contain no personal projects,
real agent conversations, account data or desktop captures. PNG files contain
only image data, with no EXIF, text comments or machine paths.

The demonstration uses a small custom colorscheme and tabline/statusline.
Studio supplies the pane backgrounds, focus treatment, layout picker and ASCII
cover. It does not install the demonstration's surrounding theme or bars.
The default Agent launcher is shown; no agent service was contacted.

| `notes.png` | Project Notes beside the editor |
